## Images

Use a path relative to `public/`.

````mdx
![Descriptive alt text](/images/projects/portfolio-site/home.png)
````

You can also use plain HTML/MDX image syntax if you need extra attributes:

````mdx
<img
  src="/images/projects/portfolio-site/home.png"
  alt="Descriptive alt text"
  width="1200"
  height="630"
/>
````

## Line breaks

Use a blank line for a new paragraph.  
Use two trailing spaces if you want a manual line break inside the same paragraph.

````mdx
First line with a manual break.  
Second line in the same paragraph.

New paragraph after a blank line.
````

## Raw HTML / MDX

Basic HTML works inside MDX when you need it.

````mdx
<div>
  <strong>Inline HTML works inside MDX.</strong>
</div>
````

## Notes

- Fenced code blocks are highlighted automatically when you add a language after the opening backticks.
- Inline code, blockquotes, tables, lists, links, and images are all styled by the site's MDX component and global CSS setup.
- Advanced `rehype-pretty-code` metadata like line highlighting or code titles is not currently customized in this repo, so stick to standard fenced blocks unless you add that support first.
